# BBMP Borewell Dashboard — IISc for BWSSB

A clean, minimal dashboard for exploring BBMP's 198 wards and the borewell sensors reporting inside them. Static site → GitHub Pages, same deployment pattern as `bbmp-borewell-dashboard`.

## Repo layout

```
Dashboard_IISC_for_BWSSB/           # (this repo)
  index.html                        # dashboard entry (map + overlays)
  css/style.css
  js/app.js
  data/                             # generated by backend/prepare_data.py
    wards.geojson
    sensors.json
    sensor_series/<uid>.json
    manifest.json
  backend/
    prepare_data.py                 # rebuild data/ from KH ZIP + shapefile + population xlsx
    sensors_db_extract.py           # dump the sensors table -> data/sensors_db.json (adds motor HP + full UID list)
    requirements.txt
  worker/                           # scaffold for a future dynamic API (empty for now)
  .github/workflows/deploy.yml      # GitHub Pages auto-deploy on push to main
  start_server.bat                  # local dev server (Windows)
  START_HERE.md                     # quickstart + publish steps
```

## Hosting

**GitHub Pages** (same as your existing dashboard). `main` → deploy workflow → Pages, live at `https://<you>.github.io/<repo>/`. Setup steps in `START_HERE.md`.

## KH filtering rules (matches your Ward-25 PPT)

A pump session = one blue-start row to the next red-end row in the KH file. A session is *usable* when all of:

- ≥ 3 water-level readings inside the session
- cumulative water yield actually increased (some volume was pumped)
- no sensor re-lock: no water-level jump > 20 ft between two consecutive samples
- no net level rise: stop level deeper than start (positive drawdown)

`prepare_data.py` currently exports the raw per-UID series; per-session filtering runs downstream. Tell me if you want the dashboard to hide unusable sessions in the charts too.

## Dashboard behaviour

- Full-screen map on load; no sidebars. Toolbar (top-right) has search / filters / about.
- Wards choropleth-shaded by sensors-with-data (toggle to total sensors or population in Filters).
- 579 sensors visible by default; bottom-right toggle reveals the rest of the KH sensor set (after you've run `sensors_db_extract.py`).
- Hover a ward → tooltip with population, area, sensor counts.
- Click a ward → panel with stats + UID list. Click a UID → sensor detail.
- Click a sensor → metadata + water-level and discharge charts (1W / 1M / 3M / All range chips; expand for full-window view).
- Search (Ctrl-K): ward name, ward number, UID; Quick views (max/min/no sensors).
